# Concept-to-build review

The generated concept (`design-concept.png`) was compared with actual desktop/browser output (`../evidence/browser/desktop.jpg`) and mobile output (`../evidence/browser/mobile.jpg`).

| Intent | Implemented result | Deliberate difference |
| --- | --- | --- |
| Paper canvas, near-black ink, acid highlight | #f4f1e9 / #232720 / #d8ed43, thin rules, dark header and screen | Real library controls replace invented concept controls. |
| Oversized condensed headline, monospace details | Impact headline and local monospace; no remote font request | Platform font metrics differ slightly from the generated image. |
| Fixed collection rail, large 16:9 film, evidence/state below | 300px desktop rail with search and scrollable catalog; real HyperFrames player and source disclosure | 56 films replace the concept's 47; later pending inventory is explicit. |
| Source example and compact flow graphic | Actual inspected TextInput wrapper summarized with synthetic displayName; all clips pin source SHA | 12-second silent films, rather than the concept's invented 10-second duration. |
| Calm mobile reading | Stacked header/collection, horizontal film navigation, full-width screen, stacked evidence/state | Native player poster required an app-owned sizing correction found during QA. |

The concept's decorative window controls, invented fullscreen button and syntax-color details were not copied as fake functionality. The final date is October 1 Pacific, corresponding to the UTC source capture, rather than the concept's UTC date. Source-screenshot game scenes are labeled and remain distinct from verified live app playback.
